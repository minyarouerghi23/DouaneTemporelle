## Description
Application Android qui simule un poste de douane pour voyageurs du temps (3 activités) :
1. MainActivity : formulaire d'enregistrement
2. VerificationActivity : scanner de paradoxe (passeport)
3. ResultActivity : verdict (vert / rouge)
